# Pesquisa na web — método

1. **Pergunta precisa** antes de buscar: o que exatamente, para decidir o quê, até quando.
2. **3 fontes independentes** para qualquer fato que vá virar decisão; preferir fonte primária (site oficial, documentação, dados) a resumo de terceiros.
3. **Recência**: datar tudo; preços e APIs mudam — dizer "em <data>".
4. **Registrar**: achado útil vira nota em `50-Conhecimento/<tema>.md` (com as fontes) ou linha na nota do projeto; pergunta sem resposta vira problema no cérebro de estudo.
5. **Responder**: conclusão em 1–2 frases, depois os dados, depois as fontes. Se a pesquisa for por voz: só a conclusão e "as fontes estão na nota".
6. Ferramentas: `WebSearch` para achar, `WebFetch`/`mcp__maos__abrir`+`ler_pagina` para ler, `recordar` para ver se o vault já sabia.
